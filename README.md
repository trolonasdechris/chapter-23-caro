✨ Caro's Constellation

Chapter 23: Written in the Stars 🌌

Un pequeño rincón del universo creado con mucho cariño para celebrar los 23 años de Caro.

Esta página web es un regalo especial de sus tres trolonas, creado para reunir recuerdos, risas, canciones, mensajes y todos esos pequeños momentos que hacen tan especial nuestra amistad.

💜 Sobre el proyecto

Caro's Constellation es una página web de cumpleaños personalizada, inspirada en las estrellas, las constelaciones y la idea de que cada recuerdo compartido es una pequeña estrella que forma parte de una historia mucho más grande.

Más que una felicitación, es una colección digital de momentos y mensajes para recordarle a Caro lo mucho que la queremos y lo importante que es para nosotras.

✨ ¿Qué encontrarás?

- Una bienvenida especial: Una introducción mágica a la constelación de Caro.

- Cartas: Tres cartas personales, una de cada amiga.

- Nuestra constelación de recuerdos: Una línea de tiempo con momentos y aventuras que hemos compartido.

- Nuestra banda sonora: Una selección de canciones que nos recuerdan a ella.

- Mensajes de cumpleaños: Pequeñas dedicatorias llenas de cariño y buenos deseos.

- Una sorpresa especial: Un mensaje final de cumpleaños y recuerdos audiovisuales.

- Detalles mágicos: Estrellas interactivas, animaciones y un pequeño zorrito que acompaña la experiencia.

🛠️ Tecnologías utilizadas

- HTML5

- CSS3

- JavaScript

Desarrollada como una página web ligera y adaptable, para que pueda disfrutarse tanto desde una computadora como desde un celular.
